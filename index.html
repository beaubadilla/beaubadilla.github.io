About

I found computer science by accident. I was on a veterinarian track in community college until an intro programming course completely redirected me — and I've been building ever since.

What keeps me here is that web apps are a license to learn anything. Whenever I get curious about a new subject, I build something around it. I'm not claiming to be a standout engineer yet, but I'm relentlessly working to become one.

Projects

Pihp

Deciding where to eat with a group is chaos — someone rattles off restaurants while everyone swipes yes or no. Pihp forces the group to be decisive through a draft and a spread of info about each spot. It's the biggest, proudest thing I've built.

I wanted to build this for two years, failing a few times because my skills weren't there yet, before it finally got off the ground. I'd learned front-end, back-end, and databases as separate college topics — never as one unit — and there was far more to JavaScript than I expected (promises and async/await gave me a proper headache). I also learned the hard way how much third-party API costs, limits, and terms of service can shape an application's whole design.

  • Vue
  • Vuex
  • Vue-Router
  • Vuetify
  • Jest
  • JavaScript
  • Firebase
